如何使用這些 PowerShell 範本？
1. 檢查參數
2. 複製並貼到 PowerShell 執行


| 部分                    | 說明                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------ |
| `$PGDumpPath`         | `pg_dump` 的執行檔路徑，例如 `pg_dump.exe` 或 `C:\Program Files\PostgreSQL\17\bin\pg_dump.exe` |
| `-h $PGHost`          | 指定 PostgreSQL 主機位址，通常是 `"localhost"`（本機）或遠端 IP                                       |
| `-p $PGPort`          | 指定連線的埠號，預設是 `5432`                                                                   |
| `-U $PGUser`          | 指定登入的使用者名稱（例如：`postgres`）                                                            |
| `-F p`                | 指定輸出格式：`p` = `plain text` 純文字 `.sql`（適用於 `psql -f` 還原）                               |
| `-f $BackupFileName`  | 指定輸出檔案名稱，例如 `"concert_test_backup.sql"`，備份內容會直接寫入這個檔案                                |
| `$PGDatabaseToBackup` | 要備份的資料庫名稱，例如 `"concert_test"`                                                        |




********** PowerShell 備份資料庫範本 **************

# 設定 PostgreSQL 連線資訊
$PGHost = "localhost"
$PGPort = "5432"
$PGUser = "postgres"
$PGPassword = "qwer1@34"
$PGDatabaseToBackup = "concert_test"
$BackupFileName = "concert_test_backup.sql"
$PGDumpPath = "pg_dump.exe"  # 請確認此路徑正確，或已加入系統 PATH

# 設定環境變數
$env:PGPASSWORD = $PGPassword
$env:PGCLIENTENCODING = "UTF8"

Write-Host "開始備份資料庫 '$PGDatabaseToBackup' 到 '$BackupFileName'..."

try {
    & $PGDumpPath -h $PGHost -p $PGPort -U $PGUser -F p -f $BackupFileName $PGDatabaseToBackup

    if (Test-Path $BackupFileName) {
        $FileSize = (Get-Item $BackupFileName).Length
        if ($FileSize -gt 0) {
            Write-Host "資料庫備份成功！備份檔案路徑：$(Get-Item $BackupFileName)"
            Write-Host "檔案大小：$([Math]::Round($FileSize / 1MB, 2)) MB"
        } else {
            Write-Warning "備份檔案 '$BackupFileName' 已建立但內容為空，備份可能失敗。請檢查錯誤訊息。"
        }
    } else {
        Write-Error "備份檔案 '$BackupFileName' 未建立。請檢查錯誤訊息。"
    }
} catch {
    Write-Error "執行 pg_dump 時發生錯誤：$($_.Exception.Message)"
    Write-Host "請確認 PostgreSQL 服務是否運行，以及使用者帳號和密碼是否正確。"
}

Write-Host "備份程序結束。"


*************** PowerShell 匯入資料庫範本 *************************

一、如果有先踢 (注意不要刪除的資料庫底下執行)
SELECT pg_terminate_backend(pid)
FROM pg_stat_activity
WHERE datname = 'concert_test' AND pid <> pg_backend_pid();

二、再刪除資料庫
DROP DATABASE concert_test;

三、到存放 concert_test_backup.sql 存放路徑執行以下指令
psql -U postgres -d concert_test -f concert_test_backup.sql
